The notice reserves names containing Y.Oz / YOz; converted/subset files use internal family Lumi Journal Ink, CSS alias JournalChinese, with the original copyright/license intact. This is an attributed web adaptation, not an official upstream WOFF2 release.

All 26006 original best-cmap Unicode mappings and advance metrics were verified across six contiguous chunks. Hinting and unsupported AAT tables were removed by FontTools; normal horizontal glyph coverage/advances are preserved. FontTools 4.68.0 and Brotli 1.2.1 were used in an ignored local conversion environment; no app/package dependencies changed. Generated metadata is in yozai-manifest.json. CSS unicode-range applies this face to CJK/fullwidth glyphs, keeping Latin and functional numbers on their intentional fonts. Unsupported glyphs use existing Chinese/system fallbacks.

Payload: 7881036 bytes (7.52 MiB), largest chunk 1494288 bytes. Full source handwriting coverage is intentionally favored over a narrow recipe-specific subset. Six chunks stay below the existing 2 MiB PWA per-file limit; all are precached offline. Initial installation therefore downloads a larger font payload. No runtime font network dependency.

Caveat: caveat.woff2, 40,464 bytes, unchanged. caveat-OFL.txt retained. English Method/Ingredients headings keep JournalHand/Caveat. No journal WenKai asset or face remains; no other runtime feature depended on it.
