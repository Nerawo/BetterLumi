# BetterLumi — 目标开关、计划计数、运动折叠及状态

分支 design/graphic-editorial，基线 c8db45b。本次完整实现附件四项修正。

## 目标开关与兼容

在现有 Goal 上新增可选 exerciseEnabled 布尔值，无需 schema/index/迁移或备份版本变更。规则：旧版本缺少该字段时继续启用；只有显式 false 才停用。所有旧记录保持原样，不根据空目标值猜测“禁用”。新建配置默认启用。

More 的运动目标标题旁新增独立勾选框。关闭时禁用目标输入和周期控件，保留原值；切换只改草稿，明确保存才创建新日期版本。重启和重新启用会恢复原有值与周期。营养目标不受影响。

日目标、周目标、日历目标状态/周达标统一使用该兼容规则。关闭后不呈现运动目标条或达标消息，实际运动总计、计划及完成记录继续显示。历史中保留关闭状态、原周期和数值。

## 计划及其他运动

- 顶层 Today's Plan：完成计划数/当前适用计划数。只有非空计划的全部练习完成才计为完成；适用性继续使用原 scheduledExercise，排除禁用或未安排计划。
- 每个计划行：仍显示内部完成练习数/练习总数。计划分钟、预估热量和部分数据提示沿用原计算。
- Other Exercise 新增原生可访问折叠，默认展开。标题保留独立实际记录的热量、分钟和部分数据提示；折叠不修改记录。
- 摘要复用 dailyAggregation，只聚合所选日本组实际记录，排除仍在计划行呈现的关联实际记录。未知保留未知，显式0仍有效。
- 全未知或空状态使用一条简短提示，不重复说明。键盘焦点使用现有主题色。

## 目标状态

范围目标区分 below / within / above；最小值目标超过最低值仍成功，运动目标超过时长/消耗目标仍成功。

禁用营养素继续显示真实摄入和 Off，不显示目标环及范围。未知与不完整使用简短本地化状态、虚线或较淡进度，不授予成就；周均热量继续显示有效天数且完整7天才正式达标。范围上限超出沿用克制陶土色。
