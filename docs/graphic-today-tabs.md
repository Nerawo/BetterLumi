# BetterLumi · Graphic Editorial Today Tabs

日期：2026-10-19。分支：design/graphic-editorial。基于上次 Graphic Editorial 提交 299863d。

## 布局与行为

页首、Food / Activity 每日概览及交互式日历始终在标签内容之前，不会随标签隐藏。保留每周/整月切换、活动环、选中日期、今日标记和日期导航。

| 标签 | 内容 |
| --- | --- |
| Food / 餐食 | 今日营养在前、餐食记录在后；热量圆环、营养实际值与目标、分餐、增删改 |
| Activity / 运动 | Daily Plans、实际运动记录、周运动计划与编辑；保留完成关联、独立折叠、训练标签及重复安排 |
| Supplements / 补剂 | 原有补剂记录、状态菜单、管理与编辑 |
| Weight / 体重 | 原有日期语义、记录与增删改、体重日记入口；从日记返回后仍在体重标签 |
| More / 其他 | 个人目标编辑与历史、待办和其他日程 |

默认进入 Food。切换日期保留当前标签；切换标签只改变展示，不更改 URL 或写入数据。隐藏面板保持挂载，保留计划和待办等展开状态。标签支持左右方向键、Home/End、可见焦点与窄屏横向滚动。

顶部概览和 Food 营养区共用一份 memoized 展示模型，继续调用现有聚合与目标计算函数。未复制营养或运动计算。补剂菜单按可用空间上下展开，避免短面板中的固定导航遮挡。

## 数据与 Git 安全

没有修改 IndexedDB 名称、版本、schema、迁移、备份格式、原始营养/运动/目标计算、图像记录或依赖。标签状态只在 React 中保存，不增加持久化字段。未更换 localhost:5173 来源。

开发与测试只使用新浏览器上下文及测试来源。四种手机/语言组合在只读操作前后比较完整导出 tables，完全相同。保存测试验证餐食、运动关联、重复安排、补剂、体重、待办和目标版本的刷新后持久化；数据库版本仍为 5，配方图片和原有内容保留。
